## 📖 About this application

The server-security-init-skill helps you set up Ubuntu or Debian servers. When you open a fresh server, it lacks basic protection. This tool applies security rules to your remote host. It works by configuring your SSH connection settings. You use it to make your server resistant to common internet attacks. It acts as a safety layer for your data and files.

## 📋 Requirements

You need a Windows computer to run this tool. Your computer requires an active internet connection. You must have access to a server running Ubuntu or Debian Linux. Do not use this tool on servers running other operating systems. Make sure you have your server IP address, your username, and your password or private key file ready.

## 🔑 Using the tool

Double-click the desktop icon to open the application. The home screen shows a simple form. Enter your server information into the blank fields.

1.  Enter the Server IP address.
2.  Provide your Linux username.
3.  Select your authentication method.
4.  Click the Connect button.

The software checks the connection to your server. It scans the current settings on the remote host. It then displays a list of security tasks. These tasks include disabling root login, updating existing software packages, and setting a firewall to block unwanted traffic.

Review the list of changes. Click the Run button to start the hardening process. The application executes these tasks one by one. You see a log of each action in the main window. Do not close the window while the program runs. It takes between two and five minutes to finish the setup.

## 🔒 Security benefits

This application provides several protections for your server. It limits how many times someone can try to guess your password. It turns off unused services that might provide a way into your server. It ensures that the system software receives security patches. These steps stop the majority of automated threats found on the internet.

## 🛠️ Troubleshooting

If the program fails to connect, verify your server credentials. Check that you typed the IP address correctly. Ensure that your internet connection stays stable during the process. If you receive an error message, copy the code and save it to a text file. 

Sometimes, your local firewall might block the connection. Temporarily turn off your local security software if the connection hangs. Check that you actually have an Ubuntu or Debian server. This tool does not work on Windows-based servers.
